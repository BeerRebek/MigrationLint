# MIG000 — Suppression without justification

| | |
|---|---|
| **Category** | hygiene |
| **Default severity** | error |
| **Scope** | migration-level |

A `[SuppressMigrationLint]` attribute was applied without a justification string. The whole point
of suppression is that a human reviewed the operation and accepted the risk — an unexplained
suppression hides that decision from the next reviewer.

This rule can never itself be suppressed.

## Bad

```csharp
[SuppressMigrationLint]
public partial class DropLegacyColumn : Migration { }
```

## Good

```csharp
[SuppressMigrationLint("LegacyNotes confirmed unused across all services (see JIRA-1234).", "MIG001")]
public partial class DropLegacyColumn : Migration { }
```

The first argument is the justification (required). Any following arguments are the rule ids to
suppress; with none, every rule is suppressed for that migration.
