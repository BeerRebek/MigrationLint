# MigrationLint v0.1.0

**The EF Core migration linter that understands database locks.**

First stable release. MigrationLint reads your EF Core migration `.cs` files — no build, no
database connection, no DbContext loading — and flags the changes that lock tables or destroy data
in production but pass code review and staging unnoticed.

## Highlights

- 🔒 **Lock-first rules** no other .NET tool has — index builds without `CONCURRENTLY`/`ONLINE`,
  unique-constraint scans, foreign keys without deferred validation, DDL mixed with data.
- 🧭 **Provider-aware** — dialect-correct guidance for **PostgreSQL, SQL Server, and MySQL**
  (plus SQLite), auto-detected from the model snapshot.
- 🤖 **CI-native** — a reusable GitHub Action (`uses: BeerRebek/MigrationLint@v1`), inline PR
  annotations, and SARIF for the Security → Code scanning tab.
- 💡 **IDE analyzer** — the same rules run inside Visual Studio / Rider as you write, with code
  fixes (add the concurrent/online annotation, add a default value, suppress with justification).
- 🎯 **Live-DB awareness** (opt-in, read-only) — real row counts suppress false positives on empty
  and small tables.
- 🧩 **Adoptable on day one** — baseline, config, per-migration suppression, and PR-diff mode.

## What's included

**Rules (13)** — each with a copy-pasteable safe alternative:

| Category | Rules |
|---|---|
| locking | MIG007 index without CONCURRENTLY/ONLINE · MIG008 unique-constraint scan · MIG009 FK without deferred validation (PG `NOT VALID` / SQL Server `WITH NOCHECK`) · MIG010 DDL mixed with data |
| dataloss | MIG001 dropped column · MIG002 dropped table · MIG003 rename · MIG005 type narrowing · MIG011 destructive raw SQL |
| failure | MIG004 NOT NULL without default · MIG006 nullable → NOT NULL |
| hygiene | MIG012 oversized migration · MIG000 suppression without justification |

**CLI** — `check`, `baseline`, `explain`, `list-rules`; console / GitHub / SARIF / JSON output;
`--category`, `--changed-only`, `--connection`, `--deployment-strategy`; rich built-in help; exit
codes `0/1/2/3`.

**GitHub Action** — `BeerRebek/MigrationLint@v1` with inline annotations, SARIF upload, and
`changed-only` PR-diff mode.

**Roslyn analyzer** (`MigrationLint.Analyzers`) — inline diagnostics + 4 code fixes.

**Live-DB awareness** — `--connection` uses `pg_class.reltuples` (PostgreSQL),
`sys.partitions` (SQL Server), and `information_schema.TABLES` (MySQL). Estimate-based, read-only,
short timeout; fails soft when the database is unreachable.

## Install (GitHub-only distribution)

```bash
git clone https://github.com/BeerRebek/MigrationLint.git
cd MigrationLint
dotnet pack src/MigrationLint.Cli/MigrationLint.Cli.csproj -c Release -o ./artifacts
dotnet tool install -g --add-source ./artifacts MigrationLint.Cli
```

Or download a `.nupkg` from this release and
`dotnet tool install -g --add-source <folder> MigrationLint.Cli`.

## Quality

- **66 tests** on `net8.0` and `net10.0`.
